# Bangladesh regional map

Source: geoBoundaries gbOpen BGD ADM1, boundary ID BGD-ADM1-32408957.

- Metadata: https://www.geoboundaries.org/api/current/gbOpen/BGD/ADM1/
- Geometry: https://github.com/wmgeolab/geoBoundaries/raw/9469f09/releaseData/gbOpen/BGD/ADM1/geoBoundaries-BGD-ADM1_simplified.geojson
- Boundaries represented: 2015; regional display only.
- Source dataset license: CC0 1.0 Universal Public Domain Dedication, as reported in the geoBoundaries metadata.

The application uses locally generated SVG paths. It groups supported self-reported district labels into regions and does not infer precise respondent coordinates. The preview activity is fictional and is independent of this boundary dataset.

Run `node scripts/build-map.cjs` to rebuild the SVG path data after updating the geometry.
